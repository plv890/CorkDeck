# CorkDeck 0.3b

Небольшое быстрое обновление по первым сообщениям об ошибках. Порядок установки и основные возможности те же, что в [0.3](RELEASE-0.3.ru.md); для обновления замените `switch/wine/wine-nx-runtime.nro` файлом из `CorkDeck-0.3b.zip`.

- **Загрузки из Steam, которые обрывались сразу.** Игра перечисляет все свои наборы файлов, а лицензия аккаунта покрывает только часть: отдельно продаваемые дополнения, язык другого региона. CorkDeck запрашивал все, и первый отказ обрывал загрузку с сообщением о недоступной лицензии (ошибка 1015). Теперь наборы, на которые нет лицензии, пропускаются, как это делает сам Steam. Если недоступным оказался выбранный язык, игра ставится на английском.
- **Игры, которые ставились без программы запуска.** Наборы файлов, помеченные в Steam как необязательные, никогда не запрашивались. У некоторых игр в таком наборе лежат исполняемые файлы, и игра скачивалась целиком, но запустить её было нечем. Теперь необязательные наборы ставятся, если их покрывает лицензия аккаунта.
- **Файлы размером 4 ГБ и больше.** Игра с таким файлом отклонялась (ошибка 3105). Теперь файл записывается по частям средствами файловой системы консоли и виден программам как один, поэтому формат карты не важен.
- **`Steam.dll` для старых игр Steam.** Игры первого поколения Steam загружают собственную `Steam.dll` от Valve, распространять которую CorkDeck не вправе. Теперь она скачивается с сервера обновлений Valve при первом запуске такой игры и сверяется по SHA-256.

Что проверено: первые два изменения — на консоли, на двух играх, которые на 0.3 падали с ошибкой 1015, а теперь устанавливаются; одна из них получила программы запуска из необязательного набора. Остальные два — только на ПК (чтение архива — на настоящем пакете Valve); игра с файлом больше 4 ГБ и игра, которой нужна `Steam.dll`, для этой версии на консоли не ставились. Проверки на ПК: 108 проходят, 1 пропущена, отказов нет.
