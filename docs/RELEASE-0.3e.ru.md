# CorkDeck 0.3e

Быстрое обновление по сообщениям об ошибках: игры Steam, которые не запускались. Порядок установки и основные возможности те же, что в [0.3](RELEASE-0.3.ru.md); для обновления замените `switch/wine/wine-nx-runtime.nro` файлом из `CorkDeck-0.3e.zip`. Включает всё из [0.3b](RELEASE-0.3b.ru.md) и [0.3c](RELEASE-0.3c.ru.md). Версии 0.3d публично не было.

- **Программы, которые перед запуском ищут работающий клиент Steam, теперь его находят.** Такая программа читает в реестре, какой процесс является клиентом Steam и где его библиотека, и идёт дальше, только если этот процесс жив. CorkDeck записывал библиотеку, но не процесс, поэтому программа решала, что Steam не запущен, и через несколько секунд закрывалась без окна и без сообщения. Именно это показал журнал пользователя.
- **Библиотека, которую CorkDeck даёт игре вместо клиента Steam, годится программам любого возраста.** Она отвечает в той версии интерфейса клиента, которую просит программа, а не только в новейшей; в ней есть функции, которые библиотека клиента Valve экспортирует по имени и которые старые программы вызывают напрямую; она собирается из того же исходника, что и библиотека Steam API. Теперь она лежит внутри приложения и записывается на карту при необходимости — отдельным файлом в пакете её больше нет.
- **На вопрос «запущен ли Steam?» даётся верный ответ ещё до инициализации Steam игрой.** Игра, которая сначала спрашивает и инициализируется только при ответе «да», раньше получала «нет» и останавливалась со своим сообщением «не удалось подключиться к Steam».
- **Программы, которые при запуске спрашивают у Windows строение процессора** (ядра, кэши), получают ответ; некоторые сразу останавливались с ошибкой, когда запрос отклонялся.
- Запрос, на который замена Steam ответить не может, записывается в журнал игры по имени — в отчёте видно, чего игра просила.

Чего это не меняет: игра, чья обёртка Steam проверяет цифровую подпись Valve у библиотеки клиента, по-прежнему не запустится; защиту от копирования CorkDeck не снимает и не обходит. См. [Совместимость](COMPATIBILITY.md#games-known-not-to-run).

Что проверено: на консоли игры, работавшие на 0.3c, запущены снова — результат и частота кадров те же; среди них игра, которая стартует через обёрнутую Steam программу запуска, и игра, которая пользуется библиотекой Steam API напрямую; игра, которую останавливает проверка подписи, останавливается на ней, как и раньше. Игры из сообщения у автора проекта нет, поэтому её саму запустить было нельзя: причина прочитана в журнале пользователя, а проходит ли игра дальше теперь — станет известно, когда попробует её владелец. Проверки на ПК: 108 проходят, 1 пропущена, отказов нет.
