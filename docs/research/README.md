# Working notes

These files are investigation notes written during development: experiments, measurements and dead ends, kept for anyone who wants to see why something was done. They describe one console and one work environment at a given date, mention local paths and addresses of that environment, and are not user documentation. Later notes can contradict earlier ones.

For the current state of the project, read the [README](../../README.md), the [release notes](../RELEASE-0.2.md) and [what has been checked](../COMPATIBILITY.md).
