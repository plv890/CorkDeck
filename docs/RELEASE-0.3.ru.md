# CorkDeck 0.3

Что изменилось по сравнению с первой публичной версией 0.2. English: [RELEASE-0.3.md](RELEASE-0.3.md).

## Изменения

### Совместимость

- **Недостающие библиотеки видны до запуска.** CorkDeck читает таблицу импорта программы, ищет каждую DLL рядом с ней и в папке Windows её разрядности и называет недостающее на странице игры и при нажатии «Играть».
- **Microsoft Visual C++ 2015–2022 добавляется сам**, включая MFC. Пакет скачивается с сайта Microsoft, сверяется по длине и SHA-256, библиотеки достаются из архивов внутри него. Пишутся только отсутствующие файлы, существующие не заменяются. Установщик Microsoft не запускается: в этой среде он не работает.
- **Локальная библиотека Steamworks отвечает так, как её вызывают игры, собранные Visual C++.** Функции, возвращающие структуру (например, идентификатор Steam), принимают скрытый адрес результата; у каждого интерфейса своя таблица в порядке этого компилятора. Игры, читающие такие результаты, больше не падают через несколько секунд после старта.
- **Есть все семейства интерфейсов Steamworks.** Добавлено тринадцать (UGC, HTTP, Controller, Inventory, Music, MusicRemote, Video, AppList, HTMLSurface, UnifiedMessages, GameServerStats, ParentalSettings, RemotePlay). Они отвечают «ничего нет», но игра, которая их импортирует, теперь загружается.
- **Библиотека Steamworks — внутри приложения.** Оно само кладёт её на карту, если её нет или версия другая: ни на новой карте, ни при обновлении одним файлом ничего копировать руками не нужно.
- **Зарегистрированы кодеки изображений Windows.** Декодеры, кодеры, конвертеры и форматы `windowscodecs` (PNG, JPEG, BMP, GIF и другие) вносятся в реестр при старте, и вспомогательные библиотеки Direct3D узнают файлы картинок.
- **Компоненты Windows — один проверенный набор.** Они скачиваются из хранилища исходного проекта строго одной ревизии, а не «что лежит там сегодня»; позднее изменение в чужом хранилище не даст новой установке непроверенный или неполный набор.

### Оболочка

- **Удаление игры с карты памяти** со страницы игры («Управление»). В вопросе названы папка, её размер и число файлов; сохранения в профиле пользователя остаются; общая папка не удаляется никогда.
- **«Хранилище»**: сколько занимает каждая игра, сколько — незавершённые загрузки, сколько свободно.
- **«Загрузки» после перезапуска** показывают незавершённые загрузки: продолжить или удалить.
- **Весь аккаунт**: вкладка «Не установленные» больше не обрезается на 256 играх; игры с большим числом пакетов открываются для установки.
- Страница игры перед установкой показывает размер и язык, на котором она будет установлена.
- **Версия на виду**: «Обслуживание» → «О программе».
- Длинные русские фразы при переносе больше не рвутся посреди буквы.
- У окна загрузки, которую не удаётся продолжить, заголовок помещается; отменённая загрузка не числится ожидающей.

### Система

- **CorkDeck не меняет частоты.** Профили разгона из 0.2 убраны, как и ускорение процессора на время установки из Steam. Разгон — дело Horizon OC. В первичной настройке больше нет шага разгона; загрузчик Horizon OC ставится только с теми настройками, что уже есть на карте.
- **Режим разработчика**, по умолчанию выключен. Без него в журналы пишутся только отказы; раздел «Диагностика», экспорт диагностики Steam и просмотр журнала по сети скрыты.
- **Запись загрузки в Hekate называется CorkDeck.** Запись «Autorun», созданная прежней версией, переименовывается на месте.
- Подробные трассы умеют записывать каждое исключение с кодом и адресом — чтобы находить, почему программа остановилась.

### Код и проверки

- Из оболочки убрано около 1900 строк прежних экранов, до которых не было пути, и переводы, которые нигде не показывались.
- **Набор проверок на ПК проходит: 108 из 109, одна пропущена** (ей нужна машина на ARM64). В 0.2 не выполнялись 26: проверки отстали от кода, части нужен был процессор ARM64, части — исходники, которых не было на машине. Проверки приведены в соответствие, ARM64-проверки идут под эмулятором, две утечки памяти в самих проверках закрыты.
- Две проверки оболочки собирают её с запретом любых предупреждений компилятора и проходят по нынешним экранам.
- Весь набор выполняется параллельно примерно за минуту.

## Обновление с 0.1 или 0.2

1. Закройте CorkDeck: **«−» → Питание → Закрыть CorkDeck**.
2. Замените на карте файл `switch/wine/wine-nx-runtime.nro` одноимённым файлом из `CorkDeck-0.3.zip`. Больше ничего копировать не нужно.
3. Запустите CorkDeck со значка в меню HOME. Игры, настройки и вход в Steam останутся.

Папку `switch/wine` для обновления не переименовывайте и не удаляйте. Если в 0.2 вы включали профиль разгона, после обновления проверьте в оверлее Horizon OC раздел приложения CorkDeck и сбросьте его, если он не нужен: 0.3 его больше не трогает. Чтобы запись в Hekate называлась CorkDeck, пройдите первичную настройку ещё раз («−» → Обслуживание → Первичная настройка), предварительно сохранив папки `atmosphere` и `bootloader`. Версию покажет «Обслуживание» → «О программе».

## Состояние

0.3 установлена из своего пакета в пустую папку на консоли: пройдены первичная настройка, загрузка компонентов Windows, перезагрузка через запись CorkDeck, вход в Steam по QR-коду, установка игры из Steam и запуск игр. Игровой процесс систематически не проверялся. Известные ограничения — в [COMPATIBILITY.md](COMPATIBILITY.md).
