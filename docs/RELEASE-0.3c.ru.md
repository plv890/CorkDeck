# CorkDeck 0.3c

Второе быстрое обновление по сообщению об ошибке. Порядок установки и основные возможности те же, что в [0.3](RELEASE-0.3.ru.md); для обновления замените `switch/wine/wine-nx-runtime.nro` файлом из `CorkDeck-0.3c.zip`. Включает всё из [0.3b](RELEASE-0.3b.ru.md).

- **Загрузки из Steam, которые обрывались сразу с ошибкой 3004 («нет подходящего сервера»).** Steam называет два вида серверов с содержимым, с которых качает клиент Steam: собственные серверы Valve и серверы сторонних сетей. CorkDeck принимал только второй вид, и только в одном домене. Во многих регионах Steam называет лишь собственные серверы Valve, и там любая игра падала ещё до начала загрузки. Теперь используются оба вида, а запись о сервере, которой приложение воспользоваться не может, пропускается и не портит весь список.

Что проверено: причина прочитана в журнале сбоев пользователя и подтверждена по открытому справочнику серверов Steam — примерно половина опрошенных регионов возвращала только тот вид, который отклонялся. Загрузка на 0.3c выполнена на консоли в регионе, где есть оба вида. В затронутом регионе проверить было негде; сообщение оттуда будет кстати. Проверки на ПК: 108 проходят, 1 пропущена, отказов нет.
