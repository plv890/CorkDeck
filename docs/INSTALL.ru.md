# Установка CorkDeck 0.2

```text
CorkDeck 0.2
==============================

CorkDeck запускает Windows-игры на Nintendo Switch. Это форк проекта
Autorun (ticoverse.com) с новой оболочкой. Совместимость зависит от игры: возможны ошибки и вылеты. Игры в пакет не входят.


ЧТО НУЖНО
---------
- Nintendo Switch с Atmosphere и возможностью запускать homebrew.
  Используйте только emuMMC: значок в меню HOME ставится как
  приложение, а за самодельные приложения консоли блокировали.
- Карта памяти: около 60 МБ под CorkDeck, около 1 ГБ под компоненты
  Windows (скачиваются из приложения) и место под ваши игры.
- Wi-Fi для первой настройки.
- Для патчей загрузки (нужны части игр) — Hekate и Atmosphere 1.11.2.


УСТАНОВКА
---------
1. Скопируйте папку switch из этого пакета в КОРЕНЬ карты памяти,
   согласившись на слияние папок. Всё ложится в switch/wine.

   Если на карте уже стоит Autorun, он лежит в той же папке
   switch/wine. Сначала переименуйте её (например, в switch/wine.old):
   CorkDeck рассчитан на чистую установку поверх пустой папки.

   ОБНОВЛЕНИЕ С CorkDeck 0.1: папку не переименовывайте. Замените
   файл switch/wine/wine-nx-runtime.nro и папку
   switch/wine/steamworks-local файлами из этого пакета. Игры,
   настройки и вход в Steam останутся.

2. Запустите CorkDeck из Homebrew Menu: в списке это
   wine-nx-runtime (файл switch/wine/wine-nx-runtime.nro).
   Homebrew Menu открывайте через игру с зажатой R (режим полного
   доступа к памяти), а не через Альбом.

   Через DBI ничего ставить не нужно: NRO не устанавливается, он
   запускается. Значок в меню HOME приложение поставит само на шаге 3.

3. При первом запуске откроется первичная настройка. По порядку:
   - значок CorkDeck в меню HOME — с него приложение получает всю
     память консоли; дальше запускайте только с него;
   - компоненты Windows — скачиваются из интернета (около 1 ГБ,
     несколько минут);
   - патчи загрузки и запись в Hekate — нужны играм, которым требуется
     нижнее адресное пространство. Ваша прежняя запись загрузки
     сохраняется. В Hekate новая запись пока называется «Autorun».
     Этот шаг меняет файлы загрузки на карте (папки atmosphere и
     bootloader). Перед ним сделайте копию этих двух папок на ПК.
     Если не уверены — выйдите из настройки кнопкой B на этом шаге:
     многие игры работают и без него.

   Настройку можно повторить: кнопка «−» → Обслуживание → Первичная
   настройка.

4. Перезагрузите консоль, в Hekate выберите запись «Autorun» и
   запускайте CorkDeck со значка в меню HOME.

   Если значок в HOME показывает старое имя, перезагрузите консоль.


КАК ДОБАВИТЬ ИГРЫ
-----------------
- Скопируйте папку установленной игры с ПК на карту, например в
  switch/wine/drive_c/Games/<игра>.
- В CorkDeck: Библиотека → X → «Добавить программу с карты» и
  выберите .exe игры.
- A на карточке открывает страницу игры; запуск — кнопкой «Играть».
- Игры Steam: «−» → Обслуживание → Аккаунт Steam (вход по QR-коду или
  паролю), затем Библиотека → вкладка «Не установленные».


УПРАВЛЕНИЕ В ОБОЛОЧКЕ
---------------------
«−»  главное меню (слева)        «+»  панель состояния (справа)
A    открыть / выбрать            B    назад
X    действия                     Y    поиск
L/R  вкладки библиотеки

Закрывайте приложение через «−» → Питание → Закрыть CorkDeck.


ЧТО НОВОГО В 0.2
----------------
- Профиль разгона для каждой игры: страница игры → настройки →
  «Профиль разгона» (экономия, баланс, производительность, экстрим).
  Нужен Horizon OC; частоты не поднимаются выше тех, что разрешены
  в нём самом, и возвращаются при повторном старте оболочки. Без Horizon OC
  настройка ничего не делает.
- Настройка «Порядок памяти x86 (TSO)» вынесена наверх своей группы.
  Выключение заметно ускоряет игры (в наших замерах до +45% кадров),
  но часть игр без неё вылетает — включайте обратно, если игра стала
  падать.
- Счётчик кадров и график времени кадра: настройки → «Показ FPS и
  времени кадра», можно включить сразу для всех программ.
- Игры Steam: выполняются установочные сценарии игры (записи реестра,
  копирование папок) — без них не запускались, например, Fallout 3
  и его лаунчер. Игры на Unity со Steamworks.NET больше не закрываются
  сразу после старта.
- Установка из Steam: если у игры нет файлов на языке системы, она
  ставится на английском. Загрузка, начатая с другим набором файлов,
  продолжается. Если загрузку не удаётся продолжить, приложение
  предлагает начать её заново (недокачанное удаляется) или отменить.
  Причины сбоев пишутся в switch/wine/logs/steam-download-failures.log.
- Если система закрывает приложению доступ к карте памяти, оно
  подключается к карте заново само, без перезапуска.
- Окна игр остаются видны, пока игра не начала рисовать сама
  (лаунчеры и окна настроек перед запуском).
- Каждый запуск игры складывается в свою папку
  switch/wine/reports/<программа>/<дата-время>.


ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ ЭТОЙ СБОРКИ
---------------------------------
- Причина, по которой система иногда закрывает доступ к карте, не
  найдена: приложение восстанавливается, но обложки игр в таком
  запуске могут не загрузиться.
- Часть старых экранов переведена не полностью и местами на
  английском.
- Отдельные игры могут завершаться с кодом 0xC0000005.
- Играм, которым нужен старый клиент Steam (например, Assassin's
  Creed 2008 года), требуется файл Steam.dll в папке
  switch/wine/steamworks-local/legacy-client. В пакет он не входит.
- Обновления самого приложения из интернета нет: новая сборка
  ставится заменой файла switch/wine/wine-nx-runtime.nro.


ЧТО ПРИСЛАТЬ, ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-------------------------------------
Папку switch/wine/logs целиком, папку switch/wine/corkdeck и папку
нужной игры из switch/wine/reports.
Перед отправкой проверьте журналы и удалите личные данные. Файл
switch/wine/steam-session.vault НЕ присылайте: это ваша сохранённая
сессия Steam.


УДАЛЕНИЕ
--------
Сначала сохраните игры и сохранения из switch/wine. Затем удалите
папку switch/wine и значок CorkDeck из меню HOME. Запись
«Autorun» в Hekate (bootloader/hekate_ipl.ini) и файлы патчей
первичная настройка добавляет отдельно от вашей записи; вашу запись
она не меняет.

----------------------------------------------------------------------
English, in short: copy the "switch" folder to the root of the SD card
(emuMMC only; rename an existing switch/wine first), start
wine-nx-runtime from the Homebrew Menu opened over a game (hold R), and
follow First set-up: it installs the HOME menu entry, downloads the
Windows components and adds a Hekate boot entry (named "Autorun" for
now). Reboot, pick that entry, start CorkDeck from the HOME menu.
Nothing is installed through DBI. Licences: switch/wine/licenses.

```
