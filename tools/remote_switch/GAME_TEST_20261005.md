## Diagnostic patch and limitations

Installed optional bounded closed log snapshots (two alternating <=16 KiB
files, approximately every two seconds) using the existing flusher thread.
They are readable through the existing sys-botbase extension during gameplay;
no additional sysmodule, listener or thread was installed. Stage/elapsed time,
frame counters and guest progress can now be recorded from the PC.
Snapshots verified live in launcher and Dishonored; footer sequence advances.
Receiving an old saved snapshot alone does not establish liveness.

Flag /switch/wine/remote-snapshot.txt is 1; remove or set 0 and relaunch to disable.
Original NRO and manifest retained as .before-live-logs-20261005 backups.
Installation record: artifacts/remote-switch-setup/live-logs-runtime-installation.json
(outside Git). No guest DLL, game file, prefix, account or firmware changes.

The on-console text path works only while the native console owns the display;
it is not an overlay over an initialized/stalled graphics backend. Normal
launcher handoff also needs separate UI work for a persistent loading panel.
graphics_presents counts present/swap calls, including failed attempts, not
verified usable frames. Screenshots and controls remain required for a play pass.

The read-only observer sends no input, saves periodic screenshots/log tails,
and leaves its game verdict Unknown for manual evidence review. Long black
screens receive at least ten minutes unless there is an explicit fatal error.
Host controller/file/observer/DPAPI fixture suite: 34 tests passed. Native ring buffer
passed UBSan; target NRO built successfully in the existing pinned container.
ASan was unavailable in that container; no ASan pass is claimed.

## Dependencies and follow-up

A cursor on black proves some input/window handling, not engine startup.
Check required DLL import failures, DLL initialization, graphics errors and
Steam API initialization separately. Valve documents steam_api DLL deployment
and SteamAPI_Init prerequisites (running client, App ID, user context, license):
https://partner.steamgames.com/doc/sdk/api#SteamAPI_Init . No Steam-specific
cause has yet been established for these fresh failing games.

Next evidence-driven fixes: identify the BASS initialization fault, analyze
Dishonored's rendering error, investigate cross-thread WoW64 contexts for Unity GC, and add a persistent loading UI. Do not replace DLLs or alter DRM/account
state based solely on the presence of a cursor.
