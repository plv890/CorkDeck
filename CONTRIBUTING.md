# Contributing

Please keep reports respectful and reproducible. English and Russian reports are welcome.

For bugs, include CorkDeck version, Switch model, Atmosphere version, whether you use emuMMC, optional Horizon OC version, game/store/version, launch EXE, relevant settings, expected and observed behaviour, and exact reproduction steps.

For compatibility reports, distinguish reaching a launcher, intro, menu and actual gameplay. Include duration and settings; a successful launch is not evidence that a complete game is playable.

Review logs before sharing. Remove account identifiers, personal paths and other private information. Never attach `steam-session.vault`, credentials, sign-in QR codes, your whole SD card or copyrighted game files.

For code changes, explain the problem, implementation and validation. Preserve upstream notices and component licences. Describe AI assistance and how the resulting changes were checked. Keep architectural changes separate from game-specific compatibility fixes.
